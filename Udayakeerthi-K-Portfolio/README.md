# Udayakeerthi K — Portfolio

A high-quality responsive portfolio built with pure HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure
- `style.css` — responsive styling, frames, gradients and animations
- `script.js` — scroll reveal, navigation, progress bar and interactions
- `assets/profile.jpg` — supplied profile photo
- `assets/Udayakeerthi-K-Resume.pdf` — supplied resume

## Run in VS Code
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

No Node.js or npm is required.

## Deploy on GitHub + Vercel
1. Create a new GitHub repository, e.g. `udayakeerthi-portfolio`.
2. Upload all files and folders from this project. Keep `assets/` in the same location.
3. On Vercel, choose **Add New → Project** and import the GitHub repository.
4. Framework Preset: **Other**.
5. Build Command: leave empty.
6. Output Directory: leave empty / root.
7. Click **Deploy**.

This is a static site, so there is no Express server and no `/api` route needed.
